# 双路突击

这是一个独立的网页射击小游戏，和原来的项目不冲突，直接放在新的目录里。

## 玩法

- 两路都会持续刷怪，怪物头上的数字就是血量。
- 增益是一堵发光墙，必须打爆数字才能拿到。
- 增益可能是更好的枪，也可能是一个同伴。
- 怪物碰到玩家会直接失败。
- 点击“看广告复活”后，当前场面会整体往后推一截，给你重新喘息的空间。

## 本地打开

最简单的方式是直接用静态服务器打开这个目录，例如：

```bash
python -m http.server 4173
```

然后访问：

```text
http://127.0.0.1:4173/web-lane-shooter/
```

如果你习惯，也可以直接用浏览器打开 `index.html`。

## 部署

这个目录可以直接丢到：

- GitHub Pages
- Vercel
- Netlify
- Cloudflare Pages
